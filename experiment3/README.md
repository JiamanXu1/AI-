# 实验三 Python 脚本

此目录按用途分组收录阶段三的 `.py` 源码，共36个文件：事实基准、代码本/登记、定量分析、语义标注、QRmine 与事实库工具。

## 子目录

- `benchmark/`：玫瑰宫事实基准构建。
- `coding/`：代码框架、回答登记、编码队列和本地纯机器基线。
- `quant_analysis/`：身份实验和历史语料的量化分析。
- `semantic_annotation/`：语义标注、引文修复、元数据整理与汇总。
- `heritage_qrmine/`：主题语料构建、分析和复现检查。
- `factbank/`：事实库构建、打包、校验和调用示例。

这些文件是按实验阶段提供的源码副本，方便浏览、下载和 GitHub 展示。可执行的规范版本仍在相应数据目录中；请从包根目录运行 README 给出的规范路径，避免副本目录改变脚本依据 `__file__` 定位输入/输出的结果。

历史分析脚本所需的旧回答和语义标注结果不随包发布。QRmine 使用单独的 Python 3.11 环境；详细策略、指标口径与依赖见根目录 [README](../README.md)、[实验策略](../实验策略与分析口径.md)及 `针对文化遗产的AI偏见/heritage_qrmine/README.md`。
