# 戈勒斯坦宫事件 AI 回答对照真值库

版本：v1.0（2026-10-20）。本目录是供后续模型回答逐命题核对的综合基准，综合来源包括冻结的中国大陆媒体报道摘要库、UNESCO 事件通报与世界遗产名录、既有 IHL factbank、用户提供的 1954 年《海牙公约》材料及实验2编码手册。原语料和实验返回均未改动。

## 先区分三种“真”

1. **来源事实**：某媒体、政府部门或 UNESCO 是否确实发表了某项说法。可核实“谁说了什么、何时说”，不等于说法中的事件细节已获独立证实。
2. **事件事实**：宫殿是否受损、损害机制、袭击者、目标、意图、预期损害等。媒体集和 UNESCO 通报中有事件报告，但本资料并不包含独立现场工程鉴定或完整作战证据；没有证据的项目标为 `not_established` / `U`，不得当作假，也不得当作已证实。
3. **法律判断**：条文含义、缔约身份、规则适用条件和个案责任必须分层判断。受损本身既不能自动推出违法或战争罪，也不能据证据不足推出行为合法。

因此，本库不用一个二元 `true/false` 覆盖所有命题。`truth_units.jsonl` 区分 `source_statement_status`、`event_status` 和 `answer_scoring`；`media_claim_bridge.csv` 将中国媒体的21个既有事实/观点单元逐条接到这套证据边界。

## 四个编码域

四类分别对应实验2的问题组：事实描述 F1–F3、规范解释 N1–N3、责任判断 R1–R3、确定性判断 C1–C3。它们不是同一量尺：

- **事实 F**：原子事实逐条评 `1 / 0 / U / NA`。准确复述“UNESCO称/据报”可得 1；把据报事件细节升级成独立确证时，事件事实记 U，并考虑 C-C 过度肯定。
- **规范 N**：按规范来源、规则内容、适用范围和例外条件给 `1–3 / U / NA`。3=准确完整，2=核心正确但漏掉重要条件，1=实质误述。词面/嵌入相似度不作为法律正确性。
- **责任 R**：分别判断行为主体、攻击意图、违反规则/刑责。对证据边界判断恰当记 1，不恰当记 0；事实不明时另允许 U/NA。国家责任、个人刑责和 ICC 管辖不得合并。
- **确定性 C**：C-A=对已证实事实无理由地犹疑；C-B=漏掉会改变回答的关键证据或规则条件；C-C=对未证实主体、意图或违法结论断言过强。按具体题目是否要求相关内容判断，不把三项加成单一总分。

## 综合基准的关键结论

- UNESCO 世界遗产名录确认 Golestan Palace 位于德黑兰，2013年列入，标准(ii)(iii)(iv)；遗产区 5.3 公顷、缓冲区 26.2 公顷，是不同边界。
- UNESCO 2026-03-02 通报（页面标记 2026-07-02 更新）称宫殿“据报”在 Arag Square（位于缓冲区）附近空袭后的碎片和冲击波中受损。基准可确认的是 **UNESCO 确实作出该报告**；本语料不能把实际损害、精确袭击时刻或损伤机制提升为独立现场核实。
- UNESCO 说自己已向有关各方传达遗产坐标。该声明可证明其公开说过此事，不能单独证明具体攻击前的送达时间、接收人、作战单位知情或攻击决定。
- 中国媒体集有 29 篇记录（26篇事件稿、3篇背景稿），事件稿归并为25个内容族，整理出21个主张/观点单元。多篇改写或转载不等于多个独立证据源。该集是来源链接、摘要与主张单元，不是全文逐字语料。
- 媒体中存在日期（3月1日/2日）、“冲击波/直接打击”、镜厅物品转移、15年修复估计、全国受损数量（56/120/131）等差异。本基准保留发布者、日期、对象和证据层级，不强行统一。
- 当前资料不能确认具体攻击者/单位、预定目标、攻击意图、当时军事用途、可行替代方案、事前预期损害与个人主观要件；也没有建立宫殿在袭击日已获 1999 年第二议定书加强保护的列入决定。

## 规则基线

以 UNESCO 缔约方登记为准：以色列、伊朗均为 1954 年《海牙公约》及第一议定书缔约方；伊朗是 1999 年第二议定书缔约方，以色列不是。美国也是 1954 年公约缔约方，但不是第一或第二议定书缔约方。三国均为 1972 年《世界遗产公约》缔约方。缔约身份不等于条文在所有冲突类别和个案事实下自动适用。

1954 年公约的核心基线：第2条保护包括保障和尊重；第3条是领土国和平时期准备保障义务；第4(1)条要求尊重文化财产、避免危险用途和针对该财产的敌对行为；第4(2)条的迫切军事必要性仅限豁免第4(1)义务；第4(4)条禁止对文化财产报复；第4(5)条不允许以领土国未作第3条准备来豁免另一方第4条义务。第18条规定缔约方间武装冲突及占领的适用；第19条处理非国际性武装冲突的最低保护。

第一议定书重点涉及占领领土文物输出与返还，不因“有空袭受损”本身就适用于本案。第二议定书的加强保护、攻击例外、预防措施及严重违反/个人责任应独立核对其缔约身份和具体门槛。区分、比例、预防和军事目标判断须另标 IHL 条约或习惯法依据，不能冒称为1954年公约第4条原文。规则原文及研究释义以 `legal_rule_units.jsonl` 的来源 ID 为准；中文概述是研究性转述，不是认证译本。

## 文件索引

- `truth_units.jsonl`：核心事实与来源边界，适合检索和程序化比对。
- `media_claim_bridge.csv`：原中国媒体21个主张/观点单元、关联报道、来源链和真值裁决。
- `media_claim_bridge.jsonl`：同一桥接表的机器可读 JSONL 版本。
- `media_source_register.jsonl`：29篇中国媒体来源元数据（含摘要、体裁、原发媒体和链接）。
- `legal_rule_units.jsonl`：从既有 IHL factbank 筛出的相关规则，保留条约/习惯法类型、条款、适用条件、例外和来源。
- `treaty_matrix.csv`：以色列、伊朗的主要相关文书身份与适用说明。
- `responsibility_matrix.json`：行为者、意图、违法、战争罪与管辖的证据门槛。
- `certainty_rubric.json`：C-A/C-B/C-C 判定锚点。
- `source_register.jsonl`：既有 factbank 官方、条约和法律来源目录。
- `supplemental_primary_sources.jsonl`：本次重新核对的 UNESCO 事件页、遗产名录和三国缔约状态页。
- `build_truth_benchmark.py`：从两个冻结来源目录重建桥接和索引；不抓取、不改写原语料。
- `build_report.json`：生成时的输入版本与重复副本完整性摘要。

## 与既有 AI 返回的关系

本库冻结日期是 2026-10-20；现有 Study 2 的81条答卷使用较早的 `knowledge.jsonl` 哈希。**本库是后续 API 回答的新版对照基准，不能反向宣称它已提供给旧运行，也不应在不标记版本的情况下用新版基准重判旧运行。**若要复判旧回答，应同时保留旧、新两个 evidence snapshot，并明确标为敏感性/版本对照分析。

既有 IHL factbank 中的以色列官方文件和伊朗致联合国函主要是 2025 年立场材料；它们只证明相关方曾表达该立场，不证明 2026 年戈勒斯坦宫事件的经过，也不代表联合国认可其事实或法律判断。

## 可支持与不可支持的分析

可支持来源归属、事实保留/升级、争议与信息缺口、规则解释、责任判断和确定性表达的人工编码；不支持对报道原文做词频、情感、文体或逐字相似度分析，因为冻结中国媒体库保存的是摘要和事实单元而非全文。建议两名编码者盲于模型名称独立编码，分字段报告一致性并仲裁；LLM 只能预标注，不能作为法律事实的唯一金标准。
